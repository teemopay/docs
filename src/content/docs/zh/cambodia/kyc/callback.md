---
title: KYC回调
description: 商户接收KYC认证结果的异步通知
---

### 回调地址

| method | url       |
|--------|-----------|
| POST   | 商户提供的回调地址 |

### 头部信息（header）

| header 参数 | 入参参数描述 |
|-----------|--------|
| timestamp | 请求时间戳  |
| nonce     | 随机值    |
| country   | KH     |
| appCode   | 应用编码   |

### KYC回调

| 参数                   | 类型     | 必需  | 长度  | 描述                            |
|----------------------|--------|-----|-----|-------------------------------|
| phone                | String | yes | 8-9 | 用户真实手机号，柬埔寨本地号码，不含区号        |
| authenticationStatus | String | yes |     | 认证状态：0-待认证、1-审核中、2-已批准、3-已拒绝、4-已失败 |
| sign                 | String | yes |     | 签名                            |

```json title=异步通知示例
{
  "phone": "101603841",
  "authenticationStatus": "2",
  "sign": "12222222222"
}
```

### 回调返回

| 参数      | 类型     | 必需  | 长度 | 描述                    |
|---------|--------|-----|----|-----------------------|
| SUCCESS | String | yes |    | 必须返回“SUCCESS”，否则会重复回调 |

```text title=回调示例
SUCCESS
```

### 状态

| 状态值 | 说明  |
|-----|-----|
| 0   | 待认证 |
| 1   | 审核中 |
| 2   | 已批准 |
| 3   | 已拒绝 |
| 4   | 已失败 |
