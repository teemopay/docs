### 时区规则

除非字段明确说明为 Unix 时间戳或 UTC 时间戳, 否则接口响应中的 `createTime`, `completeTime`, `settleTime` 等时间字段都会按照对应国家或地区的固定时区返回.

所有支持的国家和地区都使用固定 UTC 偏移, 不使用冬夏令时.

### 支持时区

| 国家/地区 | 国家码 | 时区 |
| --------- | ------ | ---- |
| 墨西哥 | MX | UTC-6 |
| 秘鲁 | PE | UTC-5 |
| 哥伦比亚 | CO | UTC-5 |
| 巴西 | BR | UTC-3 |
| 智利 | CL | UTC-4 |
| 阿根廷 | AR | UTC-3 |
| 巴基斯坦 | PK | UTC+5 |
| 印度 | IN | UTC+5:30 |
| 印度尼西亚 | ID | UTC+7 |
| 韩国 | KR | UTC+9 |
| USDT | BP | UTC+0 |

例如, 智利返回时间固定按 `UTC-4` 处理, 不会因为冬夏令时切换而变化.
