## 简介

TeemoPay 为跨境商户提供本地化支付能力, 覆盖代收、代付、账户查询、订单查询、回调通知等核心接口, 帮助商户用统一的接入方式对接不同国家和地区的本地支付网络.

我们的服务范围不只限于拉丁美洲市场. 当前文档已覆盖拉丁美洲、亚洲和 USDT 等业务场景, 商户可以根据目标市场选择对应国家的 API 文档进行接入. 不同国家的字段规则、银行列表、手机号格式、证件要求和回调字段可能存在差异, 请以对应国家页面为准.

## 步骤

<Steps>

1. 商务对接

   a. 确认开通国家、业务类型、费率、结算周期和上线计划;

   b. 我们为您开通测试商户、应用和对应国家的测试权限;

   c. 获取测试环境的 `app_code`, 商户后台账号和联调联系人.

2. 阅读接入指南

   a. 阅读 [操作手册](/zh/guides/operation-manual) 了解商户后台、应用和公钥交换流程;

   b. 阅读 [创建密钥](/zh/guides/create-keys) 生成商户公私钥, 并完成平台公钥交换;

   c. 阅读 [鉴权示例](/zh/guides/authentication) 确认请求头、签名、验签和回调验签规则;

   d. 阅读 [时区说明](/zh/guides/timezone) 确认各国家返回时间字段使用的固定时区.

3. 选择国家 API

   a. 根据业务地区进入拉丁美洲、亚洲或 USDT 对应文档;

   b. 先确认支付方式、必填字段、金额规则、手机号/证件格式、银行编码和账户类型;

   c. 按需接入代收、代付、查询和回调接口.

4. 联调验证

   a. 使用测试商户发起创建订单请求, 确认签名、`merchantOrderNo`、`callbackUrl` 和金额格式正确;

   b. 验证订单查询、回调接收、回调验签和幂等处理;

   c. 对各国家特有字段做场景验证, 例如钱包账号、银行账号、手机号前缀、证件类型等.

5. 生产上线

   a. 上线前确认生产商户、生产应用、公钥交换和回调地址已配置完成;

   b. 先进行小流量灰度, 观察创建成功率、支付成功率、回调到达率和代付结果;

   c. 灰度稳定后正式放量, 如需新增国家可按同一接入模式扩展.

</Steps>
